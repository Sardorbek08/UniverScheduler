Мои расписания

Каждое расписание хранит собственные занятия. Справочники общие для твоего браузера, чтобы не создавать одинаковые предметы и кабинеты повторно.

Мои данные

Добавь предметы, преподавателей, кабинеты, группы и время занятий здесь. Затем выбирай готовые значения при создании пары. Если удалить элемент, который уже используется, приложение попросит сначала изменить соответствующие занятия.

Резервная копия

Экспорт сохраняет расписания и справочники в JSON-файл. Excel импортирует строки из таблицы после выбора файла и позволит сопоставить столбцы.
